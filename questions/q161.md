# Question 161

## 题目

A company uses Amazon Redshift as its data warehouse service. A data engineer needs to design a physical data model. The data engineer encounters a de-normalized table that is growing in size. The table does not have a suitable column to use as the distribution key. Which distribution style should the data engineer use to meet these requirements with the LEAST maintenance overhead?

## 选项

**A.** ALL distribution

**B.** EVEN distribution

**C.** AUTO distribution

**D.** KEY distribution

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：AUTO distribution。AUTO distribution 的定位是让 Redshift 自动选择和调整 distribution style，降低长期维护开销，与题目要求直接对应。

**为什么其他选项不优：** A 没有直接解决题干的核心限制，或会增加额外复杂度；B 中的 EVEN distribution 主要用于在没有合适 distribution key 时均匀分布 rows，避免数据倾斜，在本题约束下不是最直接的选择；D 没有直接解决题干的核心限制，或会增加额外复杂度。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
