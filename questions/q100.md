# Question 100

## 题目

An insurance company stores transaction data that the company compressed with gzip. The company needs to query the transaction data for occasional audits. Which solution will meet this requirement in the MOST cost-effective way?

## 选项

**A.** Store the data in Amazon Glacier Flexible Retrieval. Use Amazon S3 Glacier Select to query the data.

**B.** Store the data in Amazon S3. Use Amazon S3 Select to query the data.

**C.** Store the data in Amazon S3. Use Amazon Athena to query the data.

**D.** Store the data in Amazon Glacier Instant Retrieval. Use Amazon Athena to query the data.

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 在满足功能和可靠性要求的前提下降低持续计算、存储或管理成本。

正确选项的关键动作是：**A**：Store the data in Amazon Glacier Flexible Retrieval. Use Amazon S3 Glacier Select to query the data.。Glacier Flexible Retrieval 的定位是低成本归档，支持分钟到小时级恢复；Glacier Select 的定位是直接对归档对象执行选择性查询，减少完整恢复的数据量，与题目要求直接对应。

**为什么其他选项不优：** B 中的 S3 Select 主要用于直接对单个 S3 object 做简单 SQL 过滤/列选择，适合轻量一次性读取，在本题约束下不是最直接的选择；C 中的 Amazon Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；D 中的 Amazon Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
