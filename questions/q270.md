# Question 270

## 题目

A company uses an Amazon RDS for Oracle database to store data for an ecommerce application. The company needs a solution to make the data in all tables available for future analytics. The solution must process data from a table named customer_complaints in near real time by using a REST API. Which solution will meet these requirements MOST cost-effectively?

## 选项

**A.** Use AWS Database Migration Service (AWS DMS) to replicate the Oracle database to an Amazon RDS for PostgreSQL database instance. Create an AWS Lambda function to process data from the PostgreSQL customer_complaints table and to call the REST API.

**B.** Create a task in AWS Database Migration Service (AWS DMS) to replicate the Oracle database to Amazon Redshift. Set the Oracle database as the source. Configure an AWS Lambda function to use the Amazon Redshift Data API to query the data from the customer_complaints table and to call the REST API. Unload the data from Amazon Redshift to Amazon S3.

**C.** Set up one AWS Database Migration Service (AWS DMS) task to stream the customer_complaints table data to Amazon Kinesis Data Streams. Set up a second AWS DMS task to send data to an Amazon S3 bucket. Configure an AWS Lambda function to process Kinesis data and to call the REST API.

**D.** Create a read replica of the Amazon RDS for Oracle database. Configure an AWS Lambda function to process data from the read replica customer_complaints table and to call the REST API.

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 实时/低延迟，并尽量减少中间缓冲和批处理层。

正确选项的关键动作是：**C**：Set up one AWS Database Migration Service (AWS DMS) task to stream the customer_complaints table data to Amazon Kinesis Data Streams. Set up a second AWS DMS task to send data to an Amazon S3 bucket. Configure an AWS Lambda function to process Kinesis data and to call the REST API.。AWS Lambda 的定位是短时、事件驱动的无服务器代码执行；Amazon S3 的定位是高持久、可扩展的对象存储，与题目要求直接对应。

**为什么其他选项不优：** A 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择；B 中的 Redshift Data API 主要用于通过 HTTPS API 执行 Redshift SQL，避免应用维护持久数据库连接，在本题约束下不是最直接的选择；D 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
