# Question 271

## 题目

A company maintains a central Amazon Redshift data warehouse that aggregates daily transactional data from Amazon RDS for PostgreSQL and Amazon Aurora MySQL. A data engineer notices that some complex transformation queries take hours to finish. The data engineer wants to optimize query performance to reduce query execution time as much as possible. Which solution will meet this requirement?

## 选项

**A.** Increase the concurrency scaling quota for the Redshift cluster.

**B.** Export the tables to an Amazon S3 bucket. Use Amazon Athena to query the data in the bucket.

**C.** Use Amazon Redshift Spectrum to create external tables based on the Redshift tables.

**D.** Use materialized views in Amazon Redshift for frequently queried data patterns.

## 答案

**D**

## 讲解

这题选 **D**。

**核心考点：** 针对题目给出的性能瓶颈选择直接的优化手段。

正确选项的关键动作是：**D**：Use materialized views in Amazon Redshift for frequently queried data patterns.。materialized view 的定位是预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream；Amazon Redshift 的定位是面向分析型数据仓库和大规模 SQL analytics，与题目要求直接对应。

**为什么其他选项不优：** A 中的 concurrency scaling 主要用于按 WLM queue 为 Redshift 临时增加并发计算容量，在本题约束下不是最直接的选择；B 中的 Amazon Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；C 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
