# Question 151

## 题目

A data engineer needs to use Amazon Neptune to develop graph applications. Which programming languages should the engineer use to develop the graph applications? (Choose two.)

## 选项

**A.** Gremlin

**B.** SQL

**C.** ANSI SQL

**D.** SPARQL

**E.** Spark SQL

## 答案

**AD**

## 讲解

这题选 **A + D**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**A**：Gremlin；**D**：SPARQL。该选项直接满足题干的关键限制，并且没有引入不必要的额外组件。

**为什么其他选项不优：** B 没有直接解决题干的核心限制，或会增加额外复杂度；C 没有直接解决题干的核心限制，或会增加额外复杂度；E 没有直接解决题干的核心限制，或会增加额外复杂度。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
