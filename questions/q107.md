# Question 107

## 题目

A data engineer notices that Amazon Athena queries are held in a queue before the queries run. How can the data engineer prevent the queries from queueing?

## 选项

**A.** Increase the query result limit.

**B.** Configure provisioned capacity for an existing workgroup.

**C.** Use federated queries.

**D.** Allow users who run the Athena queries to an existing workgroup.

## 答案

**B**

## 讲解

这题选 **B**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**B**：Configure provisioned capacity for an existing workgroup.。该选项直接满足题干的关键限制，并且没有引入不必要的额外组件。

**为什么其他选项不优：** A 没有直接解决题干的核心限制，或会增加额外复杂度；C 没有直接解决题干的核心限制，或会增加额外复杂度；D 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
