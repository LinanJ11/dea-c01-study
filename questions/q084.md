# Question 84

## 题目

A company uses Amazon EMR as an extract, transform, and load (ETL) pipeline to transform data that comes from multiple sources. A data engineer must orchestrate the pipeline to maximize performance. Which AWS service will meet this requirement MOST cost effectively?

## 选项

**A.** Amazon EventBridge

**B.** Amazon Managed Workflows for Apache Airflow (Amazon MWAA)

**C.** AWS Step Functions

**D.** AWS Glue Workflows

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 在满足功能和可靠性要求的前提下降低持续计算、存储或管理成本。

正确选项的关键动作是：**C**：AWS Step Functions。AWS Step Functions 的定位是编排跨服务的有状态工作流、重试、等待和分支，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Amazon EventBridge 主要用于事件路由和定时规则，在本题约束下不是最直接的选择；B 中的 Amazon MWAA 主要用于托管 Apache Airflow，适合较复杂 DAG，但通常比简单 AWS 原生编排更重，在本题约束下不是最直接的选择；D 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
