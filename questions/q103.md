# Question 103

## 题目

A data engineer is building a data orchestration workflow. The data engineer plans to use a hybrid model that includes some on-premises resources and some resources that are in the cloud. The data engineer wants to prioritize portability and open source resources. Which service should the data engineer use in both the on-premises environment and the cloud-based environment?

## 选项

**A.** AWS Data Exchange

**B.** Amazon Simple Workflow Service (Amazon SWF)

**C.** Amazon Managed Workflows for Apache Airflow (Amazon MWAA)

**D.** AWS Glue

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：Amazon Managed Workflows for Apache Airflow (Amazon MWAA)。Amazon MWAA 的定位是托管 Apache Airflow，适合较复杂 DAG，但通常比简单 AWS 原生编排更重，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Data Exchange 主要用于发现、订阅并集成第三方数据集，在本题约束下不是最直接的选择；B 没有直接解决题干的核心限制，或会增加额外复杂度；D 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
