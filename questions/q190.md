# Question 190

## 题目

A data engineer wants to orchestrate a set of extract, transform, and load (ETL) jobs that run on AWS. The ETL jobs contain tasks that must run Apache Spark jobs on Amazon EMR, make API calls to Salesforce, and load data into Amazon Redshift. The ETL jobs need to handle failures and retries automatically. The data engineer needs to use Python to orchestrate the jobs. Which service will meet these requirements?

## 选项

**A.** Amazon Managed Workflows for Apache Airflow (Amazon MWAA)

**B.** AWS Step Functions

**C.** AWS Glue

**D.** Amazon EventBridge

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**A**：Amazon Managed Workflows for Apache Airflow (Amazon MWAA)。Amazon MWAA 的定位是托管 Apache Airflow，适合较复杂 DAG，但通常比简单 AWS 原生编排更重，与题目要求直接对应。

**为什么其他选项不优：** B 中的 AWS Step Functions 主要用于编排跨服务的有状态工作流、重试、等待和分支，在本题约束下不是最直接的选择；C 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；D 中的 Amazon EventBridge 主要用于事件路由和定时规则，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
