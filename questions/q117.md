# Question 117

## 题目

A data engineer is building an automated extract, transform, and load (ETL) ingestion pipeline by using AWS Glue. The pipeline ingests compressed files that are in an Amazon S3 bucket. The ingestion pipeline must support incremental data processing. Which AWS Glue feature should the data engineer use to meet this requirement?

## 选项

**A.** Workflows

**B.** Triggers

**C.** Job bookmarks

**D.** Classifiers

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：Job bookmarks。job bookmark 的定位是记录 Glue 已处理的数据位置，实现增量 ETL，与题目要求直接对应。

**为什么其他选项不优：** A 没有直接解决题干的核心限制，或会增加额外复杂度；B 没有直接解决题干的核心限制，或会增加额外复杂度；D 没有直接解决题干的核心限制，或会增加额外复杂度。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
