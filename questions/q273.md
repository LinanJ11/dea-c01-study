# Question 273

## 题目

A company needs to build an extract, transform, and load (ETL) pipeline that has separate stages for batch data ingestion, transformation, and storage. The pipeline must store the transformed data in an Amazon S3 bucket. Each stage must automatically retry failures. The pipeline must provide visibility into the success or failure of individual stages. Which solution will meet these requirements with the LEAST operational overhead?

## 选项

**A.** Chain AWS Glue jobs that perform each stage together by using job triggers. Set the MaxRetries field to 0.

**B.** Deploy AWS Step Functions workflows to orchestrate AWS Lambda functions that ingest data. Use AWS Glue jobs to transform the data and store the data in the S3 bucket.

**C.** Build an Amazon EventBridge based pipeline that invokes AWS Lambda functions to perform each stage.

**D.** Schedule Apache Airflow directed acyclic graphs (DAGs) on Amazon Manages Workflows tor Apache Airflow (Amazon MWAA) to orchestrate pipeline steps. Use Amazon Simple Queue Service (Amazon SQS) to ingest data. Use AWS Glue jobs to transform data and store the data in the S3 bucket.

## 答案

**B**

## 讲解

这题选 **B**。

**核心考点：** 满足功能要求的同时尽量使用托管能力、减少自建组件和维护工作。

正确选项的关键动作是：**B**：Deploy AWS Step Functions workflows to orchestrate AWS Lambda functions that ingest data. Use AWS Glue jobs to transform the data and store the data in the S3 bucket.。AWS Glue 的定位是托管 ETL、Crawler、Data Catalog 及相关数据集成能力；AWS Step Functions 的定位是编排跨服务的有状态工作流、重试、等待和分支，与题目要求直接对应。

**为什么其他选项不优：** A 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；C 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择；D 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
