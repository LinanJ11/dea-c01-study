# Question 276

## 题目

A data engineer uploads confidential documents to an Amazon S3 bucket every day. The data engineer requires a solution to independently verify the integrity of all uploaded data to confirm that there was no corruption during the transfer process. Which solution will meet this requirement?

## 选项

**A.** Download a subset of the data after the data is uploaded to the S3 bucket. Manually validate the objects for integrity.

**B.** Change the default encryption on the S3 bucket to server-side encryption with customer-provided keys (SSE-C). Turn on S3 bucket keys to validate data integrity.

**C.** Calculate the SHA-256 checksum for the objects before uploading the objects. Pass the calculated value to the AWS SDK in each upload request.

**D.** Download the complete data after the data is uploaded to the S3 bucket. Programmatically validate the objects for integrity.

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：Calculate the SHA-256 checksum for the objects before uploading the objects. Pass the calculated value to the AWS SDK in each upload request.。该选项直接满足题干的关键限制，并且没有引入不必要的额外组件。

**为什么其他选项不优：** A 中的 S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择；B 中的 SSE-C 主要用于由客户自行提供和管理 S3 server-side encryption key，管理负担更高，在本题约束下不是最直接的选择；D 中的 S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
