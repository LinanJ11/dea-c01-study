# Question 275

## 题目

A company stores data in Amazon S3 and Amazon RDS. The company needs to apply technical controls to meet security requirements. The company must generate backups of the data and retain the backups for specified retention periods. The company must protect the backups from accidental or malicious deletion during the retention periods. Which solution will meet these requirements with the LEAST operational overhead?

## 选项

**A.** Create S3 buckets with versioning and MFA Delete enabled. Set a backup retention period and backup window for each RDS DB instance. Use the automated backup feature of Amazon RDS, and take additional snapshots as required.

**B.** Create S3 buckets with versioning and Same-Region Replication enabled. Set a backup retention period and backup window for each RDS DB instance. Use the automated backup feature of Amazon RDS. Take additional snapshots as required.

**C.** Create a backup plan in AWS Backup. Specify the backup schedule, set window and lifecycle values, and select a backup vault. Assign the Amazon S3 and Amazon RDS resources to the backup plan. Create a vault lock in compliance mode.

**D.** Create S3 buckets with versioning and Cross-Region Replication enabled. Set a backup retention period and backup window for each RDS DB instance. Use Amazon RDS automated backups. Take additional snapshots as required.

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 满足功能要求的同时尽量使用托管能力、减少自建组件和维护工作。

正确选项的关键动作是：**C**：Create a backup plan in AWS Backup. Specify the backup schedule, set window and lifecycle values, and select a backup vault. Assign the Amazon S3 and Amazon RDS resources to the backup plan. Create a vault lock in compliance mode.。Amazon RDS 的定位是托管关系数据库；Amazon S3 的定位是高持久、可扩展的对象存储，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Amazon RDS 主要用于托管关系数据库，在本题约束下不是最直接的选择；B 中的 Amazon RDS 主要用于托管关系数据库，在本题约束下不是最直接的选择；D 中的 Amazon RDS 主要用于托管关系数据库，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
