# Question 246

## 题目

A data engineer configures a large number of AWS Glue jobs that all start up around the same time. All the jobs run for less than 1 hour in the same subnet of the same VPC. All the AWS Glue jobs run on a G1.X worker type. Some of the jobs occasionally fail with the following error: "The specified subnet does not have enough free addresses to satisfy the request". What is the likely root cause of the error?

## 选项

**A.** There are not enough IP addresses in the subnet.

**B.** The G1.X worker type cannot access the subnet.

**C.** AWS Glue does not have the correct IAM permissions to add additional IP addresses to the subnet.

**D.** There are not enough IP addresses in the VPC.

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**A**：There are not enough IP addresses in the subnet.。该选项直接满足题干的关键限制，并且没有引入不必要的额外组件。

**为什么其他选项不优：** B 没有直接解决题干的核心限制，或会增加额外复杂度；C 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；D 没有直接解决题干的核心限制，或会增加额外复杂度。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
