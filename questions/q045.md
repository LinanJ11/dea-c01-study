# Question 45

## 题目

A company uses Amazon Athena to run SQL queries for extract, transform, and load (ETL) tasks by using Create Table As Select (CTAS). The company must use Apache Spark instead of SQL to generate analytics. Which solution will give the company the ability to use Spark to access Athena?

## 选项

**A.** Athena query settings

**B.** Athena workgroup

**C.** Athena data source

**D.** Athena query editor

## 答案

**B**

## 讲解

这题选 **B**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**B**：Athena workgroup。Athena workgroup 的定位是隔离 Athena 查询、查询历史、结果和资源控制；Athena 的定位是直接对 S3 数据执行 serverless SQL 查询，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；C 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；D 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
