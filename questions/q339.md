# Question 339

## 题目

A company stores a large dataset in an Amazon S3 bucket. A data engineer frequently runs complex queries on the dataset by using Amazon Athena. The data engineer needs to optimize query performance and optimize costs for queries that are run multiple times with the same parameters. Which solution will meet these requirements?

## 选项

**A.** Convert the dataset to JSON format before running Athena queries.

**B.** Use Amazon EMR to pre-process the data before running Athena queries.

**C.** Configure query result reuse settings in the Athena workgroup.

**D.** Use Amazon Redshift Spectrum to query the data in Amazon S3.

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 针对题目给出的性能瓶颈选择直接的优化手段。

正确选项的关键动作是：**C**：Configure query result reuse settings in the Athena workgroup.。Athena workgroup 的定位是隔离 Athena 查询、查询历史、结果和资源控制；Athena 的定位是直接对 S3 数据执行 serverless SQL 查询，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；B 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；D 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
