# Question 285

## 题目

A company is uploading log files from on-premises servers to an Amazon S3 bucket. The company needs to validate that the logs from the on-premises server are the same as the logs that are stored in the S3 bucket. Which solution will meet this requirement?

## 选项

**A.** Use the AWS SDK to automatically compute CRC32 checksums during the upload. Store the checksums in S3 object metadata.

**B.** Create an AWS Lambda function to calculate SHA-256 checksums. Store results in a separate metadata table. Validate the logs after the upload.

**C.** Enable S3 Object Lock in compliance mode on the S3 bucket. Upload the objects to the bucket.

**D.** After uploading the objects to the S3 bucket, enable S3 Object Lock in governance mode on the S3 objects.

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**A**：Use the AWS SDK to automatically compute CRC32 checksums during the upload. Store the checksums in S3 object metadata.。S3 的定位是高持久、可扩展的对象存储，与题目要求直接对应。

**为什么其他选项不优：** B 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择；C 中的 S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择；D 中的 S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
