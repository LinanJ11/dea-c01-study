# Question 50

## 题目

A company uses Amazon Redshift for its data warehouse. The company must automate refresh schedules for Amazon Redshift materialized views. Which solution will meet this requirement with the LEAST effort?

## 选项

**A.** Use Apache Airflow to refresh the materialized views.

**B.** Use an AWS Lambda user-defined function (UDF) within Amazon Redshift to refresh the materialized views.

**C.** Use the query editor v2 in Amazon Redshift to refresh the materialized views.

**D.** Use an AWS Glue workflow to refresh the materialized views.

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：Use the query editor v2 in Amazon Redshift to refresh the materialized views.。materialized view 的定位是预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream；query editor v2 的定位是可在 Redshift 控制台调度 SQL/stored procedure/materialized view refresh 等查询任务，与题目要求直接对应。

**为什么其他选项不优：** A 中的 materialized view 主要用于预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream，在本题约束下不是最直接的选择；B 中的 materialized view 主要用于预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream，在本题约束下不是最直接的选择；D 中的 materialized view 主要用于预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
