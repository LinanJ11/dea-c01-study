# Question 334

## 题目

A company runs concurrent analytical queries on Amazon Redshift tables multiple times each day. The queries require consistent data views three times each day. The company runs extract, transform, and load (ETL) operations that update dimension tables while the queries run. The company has noticed that the queries cause table-level locks during the ETL operations. The company’s current solution experiences query timeouts and deadlocks during peak processing hours, which affects analytical reporting and on-demand analysis. Which solution will fix this issue?

## 选项

**A.** Use Amazon Redshift materialized views for analytical queries. Schedule ETL operations during off-peak hours to minimize lock contention.

**B.** Configure Amazon Redshift federated queries to access source data directly. Use read replicas to isolate analytical workloads from ETL operations.

**C.** Use Amazon Redshift Spectrum to query data in Amazon S3 for analytical workloads. Maintain ETL operations on Amazon Redshift tables with transaction isolation.

**D.** Deploy separate Amazon Redshift clusters for ETL and analytics workloads. Use cross-database queries and data sharing to maintain data consistency.

## 答案

**D**

## 讲解

这题选 **D**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**D**：Deploy separate Amazon Redshift clusters for ETL and analytics workloads. Use cross-database queries and data sharing to maintain data consistency.。data sharing 的定位是让 Redshift producer 与 consumer 共享 live data，consumer 使用自己的计算资源；Amazon Redshift 的定位是面向分析型数据仓库和大规模 SQL analytics，与题目要求直接对应。

**为什么其他选项不优：** A 中的 materialized view 主要用于预计算并物化查询结果；在 Redshift streaming ingestion 中也可直接消费 Kinesis/MSK stream，在本题约束下不是最直接的选择；B 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择；C 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
