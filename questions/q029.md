# Question 29

## 题目

A data engineer needs to use AWS Step Functions to design an orchestration workflow. The workflow must parallel process a large collection of data files and apply a specific transformation to each file. Which Step Functions state should the data engineer use to meet these requirements?

## 选项

**A.** Parallel state

**B.** Choice state

**C.** Map state

**D.** Wait state

## 答案

**C**

## 讲解

这题选 **C**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**C**：Map state。该选项直接满足题干的关键限制，并且没有引入不必要的额外组件。

**为什么其他选项不优：** A 没有直接解决题干的核心限制，或会增加额外复杂度；B 没有直接解决题干的核心限制，或会增加额外复杂度；D 没有直接解决题干的核心限制，或会增加额外复杂度。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
