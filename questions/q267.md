# Question 267

## 题目

A data engineer needs to analyze time-sensitive sales data. The company stores the data in an Amazon S3 bucket. The data engineer uses AWS Glue Data Catalog to access the data. When the data engineer performs the analysis, the data engineer notices that some records are missing or out of date. What is the likely cause of these issues?

## 选项

**A.** AWS Glue Data Catalog is not up to date with the latest S3 partition changes.

**B.** Incorrect IAM roles are assigned to the AWS Glue jobs.

**C.** Versioning is not enabled on the S3 bucket.

**D.** The AWS Glue job schedules overlap with one another.

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**A**：AWS Glue Data Catalog is not up to date with the latest S3 partition changes.。Data Catalog 的定位是集中存放 database/table/schema/partition metadata；AWS Glue 的定位是托管 ETL、Crawler、Data Catalog 及相关数据集成能力，与题目要求直接对应。

**为什么其他选项不优：** B 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；C 中的 S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择；D 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
