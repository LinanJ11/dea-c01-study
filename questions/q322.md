# Question 322

## 题目

A company uses Amazon Redshift for its data warehouse. A data engineer must query a table named `orders.complete_orders_history`, which contains 100 columns. The query must return all columns except columns named `companyId` and `unique_system_id`.

Which Amazon Redshift SQL statement will meet this requirement?

## 选项

**A.** `SELECT * EXCLUDE company_id, unique_system_id FROM orders.complete_orders_history;`

**B.** `SELECT * NOT IN company_id, unique_system_id FROM orders.complete_orders_history;`

**C.** `SELECT * EXCEPT company_id, unique_system_id FROM orders.complete_orders_history;`

**D.** `SELECT * TRUNCATE company_id, unique_system_id FROM orders.complete_orders_history;`

## 答案

**A**

## 讲解

这题选 **A**。Amazon Redshift 支持在 `SELECT *` 后使用 `EXCLUDE` 排除不需要返回的列，因此不用手工列出剩余的 98 个 column。`NOT IN` 是条件判断语法，`EXCEPT` 通常用于集合/结果集差异而不是这里的 column exclusion，`TRUNCATE` 更不是 SELECT 列表语法。

**考试记忆点：** Redshift 要“SELECT 全部列，但排除少数列” → `SELECT * EXCLUDE col1, col2 ...`。
