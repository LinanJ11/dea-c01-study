# Question 252

## 题目

A company wants to use Apache Spark jobs that run on an Amazon EMR cluster to process streaming data. The Spark jobs will transform and store the data in an Amazon S3 bucket. The company will use Amazon Athena to perform analysis. The company needs to optimize the data format for analytical queries. Which solutions will meet these requirements with the SHORTEST query times? (Choose two.)

## 选项

**A.** Use Avro format. Use AWS Glue Data Catalog to track schema changes.

**B.** Use ORC format. Use AWS Glue Data Catalog to track schema changes.

**C.** Use Apache Parquet format. Use an external Amazon DynamoDB table to track schema changes.

**D.** Use Apache Parquet format. Use AWS Glue Data Catalog to track schema changes.

**E.** Use ORC format. Store schema definitions in separate files in Amazon S3.

## 答案

**BD**

## 讲解

这题选 **B + D**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**B**：Use ORC format. Use AWS Glue Data Catalog to track schema changes.；**D**：Use Apache Parquet format. Use AWS Glue Data Catalog to track schema changes.。Data Catalog 的定位是集中存放 database/table/schema/partition metadata；AWS Glue 的定位是托管 ETL、Crawler、Data Catalog 及相关数据集成能力；Parquet 的定位是列式文件格式，支持 column pruning 并减少 Athena/Redshift Spectrum 扫描量，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Data Catalog 主要用于集中存放 database/table/schema/partition metadata，在本题约束下不是最直接的选择；C 中的 Parquet 主要用于列式文件格式，支持 column pruning 并减少 Athena/Redshift Spectrum 扫描量，在本题约束下不是最直接的选择；E 中的 Amazon S3 主要用于高持久、可扩展的对象存储，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
