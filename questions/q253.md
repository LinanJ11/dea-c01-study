# Question 253

## 题目

A company adds new data to a large CSV file in an Amazon S3 bucket every day. The file contains company sales data from the previous 5 years. The file currently includes more than 5,000 rows. The CSV file structure is shown below with sample data: The company needs to use Amazon Athena to run queries on the CSV file to fetch data from a specific time period. Which solution will meet this requirement MOST cost-effectively?

## 选项

**A.** Write an Apache Spark script to convert the CSV data to JSON format. Create an AWS Glue job to run the script every day. Catalog the JSON data in AWS Glue. Run the Athena queries on the JSON data.

**B.** Use prefixes to partition the data in the S3 bucket. Use the SALE_DATE column to create a partition for each day. Catalog the data in AWS Glue and ensure that the partitions are added. Update the Athena queries to use the new partitions.

**C.** Launch an Amazon EMR cluster. Specify AWS Glue Data Catalog as the default Apache Hive metastore. Use Presto in Trino to run queries on the data.

**D.** Create an Amazon RDS database. Create a table named SALES that matches the schema of the CSV file. Create an index on the SALE_DATE column. Create an AWS Lambda function to load the CSV data into the RDS database. Use S3 Event Notifications to invoke the Lambda function.

## 答案

**B**

## 讲解

这题选 **B**。

**核心考点：** 在满足功能和可靠性要求的前提下降低持续计算、存储或管理成本。

正确选项的关键动作是：**B**：Use prefixes to partition the data in the S3 bucket. Use the SALE_DATE column to create a partition for each day. Catalog the data in AWS Glue and ensure that the partitions are added. Update the Athena queries to use the new partitions.。Athena 的定位是直接对 S3 数据执行 serverless SQL 查询；AWS Glue 的定位是托管 ETL、Crawler、Data Catalog 及相关数据集成能力，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；C 中的 Data Catalog 主要用于集中存放 database/table/schema/partition metadata，在本题约束下不是最直接的选择；D 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
