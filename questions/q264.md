# Question 264

## 题目

A company needs a solution to automatically ingest data from an Amazon S3 bucket to an Amazon Redshift table every day. The company must obfuscate sensitive data in Amazon Redshift. Users must not be able to view the sensitive data as plaintext. Which solution will meet these requirements with the LEAST operational overhead?

## 选项

**A.** Enable Amazon Macie for the company's AWS account. Configure a sensitive data discovery job for the S3 bucket. Configure an AWS Glue job to load the data into Amazon Redshift.

**B.** Enable Amazon Macie for the company's AWS account. Configure an AWS Glue job to flag and obfuscate data columns based on the Macie analysis. Load the data into Amazon Redshift.

**C.** Configure an AWS Glue job to read the data from the S3 bucket, detect and obfuscate sensitive data, and load the data into Amazon Redshift.

**D.** Configure an AWS Glue job to load the data into Amazon Redshift. Use Amazon Redshift to detect the sensitive data, create masking policies, and apply dynamic masking.

## 答案

**D**

## 讲解

这题选 **D**。

**核心考点：** 满足功能要求的同时尽量使用托管能力、减少自建组件和维护工作。

正确选项的关键动作是：**D**：Configure an AWS Glue job to load the data into Amazon Redshift. Use Amazon Redshift to detect the sensitive data, create masking policies, and apply dynamic masking.。masking policies 的定位是根据用户/角色在查询时动态遮蔽敏感字段；AWS Glue 的定位是托管 ETL、Crawler、Data Catalog 及相关数据集成能力，与题目要求直接对应。

**为什么其他选项不优：** A 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；B 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；C 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
