# Question 336

## 题目

A company uses Amazon Redshift to store order transactions from the current day. The company has an orders table that contains the previous order data. The company also has a staging table that contains new or updated order records. The company needs to remove stale records from the orders table and insert the most recent data in the orders table from the staging table. Several downstream applications need the orders table to display up-to-date information. Which solution will meet these requirements?

## 选项

**A.** Use Amazon Redshift Spectrum to delete stale records from the orders table and insert records from the staging table into the orders table.

**B.** Unload the orders table and the staging table to Amazon S3. Delete stale orders table data and insert new staging table data in Amazon S3 by using Amazon Athena. Copy the orders S3 table to the orders Amazon Redshift table.

**C.** Use Amazon Athena federated queries to read stale records from the orders table. Delete the stale records and insert the records from the staging table into the orders table.

**D.** Write an Amazon Redshift stored procedure that deletes the stale records from the orders table and inserts new records from the staging table.

## 答案

**D**

## 讲解

这题选 **D**。

**核心考点：** 识别题目要求的 AWS 能力，并选择最直接、最匹配的托管方案。

正确选项的关键动作是：**D**：Write an Amazon Redshift stored procedure that deletes the stale records from the orders table and inserts new records from the staging table.。Amazon Redshift 的定位是面向分析型数据仓库和大规模 SQL analytics；RDS 的定位是托管关系数据库，与题目要求直接对应。

**为什么其他选项不优：** A 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择；B 中的 Amazon Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择；C 中的 Amazon Athena 主要用于直接对 S3 数据执行 serverless SQL 查询，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
