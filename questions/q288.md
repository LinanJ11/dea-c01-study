# Question 288

## 题目

A company needs to transform IoT sensor data in near real time before the company stores the data in an Amazon S3 bucket. The data is available from a data stream in Amazon Kinesis Data Streams. The company needs to apply complex and stateful transformations to the data before the company stores the data. Which solution will meet these requirements with the LEAST operational overhead?

## 选项

**A.** Schedule AWS Glue ETL jobs to process the data stream.

**B.** Configure an application in Amazon Managed Service for Apache Flink to process the data stream.

**C.** Configure an AWS Lambda function to process the data stream.

**D.** Schedule Apache Spark jobs on an Amazon EMR cluster to process the data stream.

## 答案

**B**

## 讲解

这题选 **B**。

**核心考点：** 实时/低延迟，并尽量减少中间缓冲和批处理层。

正确选项的关键动作是：**B**：Configure an application in Amazon Managed Service for Apache Flink to process the data stream.。Amazon Managed Service for Apache Flink 的定位是托管实时流处理；Apache Flink 的定位是实时流处理，与题目要求直接对应。

**为什么其他选项不优：** A 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；C 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择；D 中的 Amazon EMR 主要用于运行 Spark/Hadoop/HBase/Flink 等大数据框架，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
