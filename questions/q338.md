# Question 338

## 题目

A media company wants to build a real-time analytics pipeline to process customer activity events across the company's website and mobile app. The company wants to build a solution to ingest millions of events with minimum latency. The solution must be scalable and durable enough so that no data is lost. Which solution will meet these requirements in the MOST cost-effective way?

## 选项

**A.** Set up an Amazon Kinesis Data Streams pipeline to ingest data, process the data by using AWS Lambda functions, and store the results in Amazon Redshift for analytics.

**B.** Schedule an AWS Glue job to fetch user interaction logs every 10 minutes from Amazon S3. Configure the AWS Glue job to transform and store the data in Amazon Redshift for analytics.

**C.** Configure Amazon S3 Event Notifications to invoke an AWS Lambda function to process every new interaction log file. Store the result in Amazon Redshift for analytics.

**D.** Deploy an Amazon Managed Streaming for Apache Kafka (Amazon MSK) cluster. Use self-managed consumers to process and distribute data in real-time. Integrate with Amazon Redshift for enhanced analytics.

## 答案

**A**

## 讲解

这题选 **A**。

**核心考点：** 实时/低延迟，并尽量减少中间缓冲和批处理层。

正确选项的关键动作是：**A**：Set up an Amazon Kinesis Data Streams pipeline to ingest data, process the data by using AWS Lambda functions, and store the results in Amazon Redshift for analytics.。AWS Lambda 的定位是短时、事件驱动的无服务器代码执行；Amazon Redshift 的定位是面向分析型数据仓库和大规模 SQL analytics，与题目要求直接对应。

**为什么其他选项不优：** B 中的 AWS Glue 主要用于托管 ETL、Crawler、Data Catalog 及相关数据集成能力，在本题约束下不是最直接的选择；C 中的 AWS Lambda 主要用于短时、事件驱动的无服务器代码执行，在本题约束下不是最直接的选择；D 中的 Amazon Redshift 主要用于面向分析型数据仓库和大规模 SQL analytics，在本题约束下不是最直接的选择。

**考试记忆点：** 先锁定题干明确给出的限制（例如 latency、cost、operational overhead、security），再选能最直接满足该限制的 AWS 原生能力。
